# Репетитор

Сайт для репетитора, учеников и родителей: группы и расписание, домашние задания с файлами, материалы занятий,
абонементы и посещаемость, отчёты родителям и push-уведомления. Раньше это был Telegram-бот.

**Кто что видит**

- **Репетитор:**
  - «Сегодня» — занятия, работы на проверку, заканчивающиеся абонементы, отчёты родителям;
  - «Неделя»;
  - «Группы» — ученики, приглашения, расписание, место занятий, ДЗ;
  - «Проверка» — сданные работы.
- **Ученик:** расписание («Не смогу прийти»), задания и сдача работ, оценки, материалы занятий, счётчик абонемента.
- **Родитель:** то же по своему ребёнку (детям), но без содержимого заданий и ответов. Видит сумму абонемента
  и получает отчёт за неделю.

## Запуск на ноутбуке

Нужен только Docker Desktop: Java, Gradle и Node собирают всё внутри Docker.

1. Один раз создайте тома для базы и файлов (они переживают пересоздание контейнеров):
   ```bash
   docker volume create repitbot_web_pgdata
   docker volume create repitbot_files
   ```
2. Создайте файл настроек и впишите пароль базы (`openssl rand -hex 16`):
   ```bash
   cp .env.example .env
   chmod 600 .env
   ```
3. Запустите:
   ```bash
   docker compose up -d --build
   ```
   Первая сборка качает зависимости (на медленном интернете — минут 10–15), следующие занимают 10–20 секунд.
4. Откройте http://localhost:8080. При первом запуске в журнале появится одноразовая ссылка для настройки
   аккаунта репетитора:
   ```bash
   docker compose logs app | grep setup
   ```

## Как люди попадают на сайт

- **Ученик:** группа → «+ Пригласить ученика» → «Поделиться» (WhatsApp, Telegram, SMS) или QR-код при встрече.
  По ссылке ученик сам задаёт имя, логин и пароль и соглашается на обработку данных. Ссылка одноразовая, действует 7 дней.
- **Родитель:** карточка ученика → «Ссылка для родителя».
- **Забыли пароль:** карточка ученика или родителя → «Ссылка для нового пароля» (действует сутки). После смены пароля
  все прежние входы закрываются.

Регистрации без приглашения нет, email и SMS не нужны.

## Уведомления

Всё, что раньше бот писал в чат, приходит push-уведомлением и остаётся в ленте (колокольчик в шапке).

- Включаются на каждом устройстве отдельно: карточка «Включите уведомления» на главной или «Настройки → Уведомления».
- Нужен https: на ноутбуке работает адрес `localhost`, на телефоне — только с сервером и доменом (шаг 7).
- **iPhone** (iOS 16.4+): только у сайта, добавленного на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»).
- **Android**: работают в Chrome (проверено). Яндекс Браузер и Samsung Internet проверим на шаге 7 на настоящих
  телефонах. Если браузер откажет с «Этот браузер не поддерживается для уведомлений», его службу нужно добавить
  в список `HOSTS` в `WebPush.java` — адрес будет в журнале сайта. На Xiaomi, Huawei и Honor отключите для браузера
  экономию батареи.
- Текст уведомлений шифруется ключами браузера (RFC 8291): службы Google и Apple, через которые идёт push, его не видят.
  Ключи сайта (VAPID) создаются при первом запуске и хранятся в базе — в таблице `app_keys`.

Расписание напоминаний: за сутки и за час до занятия, утренняя сводка репетитору (`DIGEST_TIME`), отчёты родителям
(`REPORT_DAY`, `REPORT_TIME`; за час до этого — напоминание дописать комментарии).

## Команды

| Что сделать | Команда |
|---|---|
| Запустить или обновить после изменений кода | `docker compose up -d --build` |
| Остановить (данные сохраняются) | `docker compose stop` |
| Журнал сайта | `docker compose logs -f app` |
| Открыть с телефона без сервера (адрес в журнале, меняется) | `docker compose --profile phone up -d`, затем `docker compose logs tunnel` |

Чего не делать:

- `docker compose build --no-cache` — сбрасывает кэш зависимостей, и следующая сборка снова качает всё (10+ минут).
- `docker compose down -v` и удаление томов `repitbot_web_pgdata` / `repitbot_files`: это база и файлы.

## Резервные копии

Сервис `backup` раз в сутки (и при каждом запуске) кладёт в `backups/` два файла: дамп базы `repitbot-ДАТА.dump`
и архив файлов `files-ДАТА.tar`. Копии старше 14 дней удаляются сами.

Копии содержат персональные данные учеников: папка доступна только владельцу, не попадает в git, её нельзя
пересылать. На сервере копии нужно дополнительно увозить на другой диск — это часть шага 7.

**Восстановление.** Текущие данные заменятся данными из копии:

```bash
docker compose stop app
docker compose exec -T db pg_restore -U repitbot -d repitbot --clean --if-exists < backups/repitbot-ГГГГММДД-ЧЧММ.dump
docker run --rm -v repitbot_files:/data/files -v "$PWD/backups":/backups:ro alpine \
  tar -xf /backups/files-ГГГГММДД-ЧЧММ.tar -C /data/files
docker compose start app
```

## Безопасность

- **Вход:** логин и пароль (BCrypt). Сессия хранится в cookie `sid` (HttpOnly, SameSite=Lax, Secure на https) и
  живёт 180 дней. Не больше 10 попыток входа на логин и 50 на адрес за 15 минут. Запросы с чужих сайтов
  отклоняются по заголовку `Origin`.
- **Права** проверяются на сервере в каждом запросе. Чужое задание, файл или работа отвечают 404, как будто их нет.
- **Файлы:**
  - тип определяется по содержимому, а не по расширению: принимаются фото, PDF, документы Office, текст, аудио, видео;
  - до 20 МБ;
  - всё, кроме картинок, отдаётся только на скачивание;
  - ученик или родитель загружает не больше 100 файлов в сутки;
  - прикрепить можно только свой файл.
- **Заголовки:** строгая CSP (скрипты, стили и шрифты только с этого сайта, без `unsafe-inline`), запрет встраивания
  в чужие страницы, `nosniff`, HSTS на https.
- **Push** уходит только на известные службы (Google, Apple, Mozilla, Microsoft и, предположительно, Яндекс), поэтому через адрес
  подписки нельзя заставить сервер обращаться куда-то ещё.
- **Контейнеры:** без привилегий, файловая система только для чтения (кроме папки файлов). База наружу не открыта.
  Сайт на ноутбуке слушает только `127.0.0.1`.
- **Данные по 152-ФЗ:**
  - согласие даётся при регистрации;
  - «Удалить мои данные» есть в настройках, репетитор удаляет данные в течение 30 дней;
  - ученики без занятий больше года удаляются автоматически.

## Устройство

```
backend/                       Java 21, Spring Boot 4, PostgreSQL 16, Flyway
  src/main/java/ru/repitbot/
    api/                       REST для сайта: представления экранов и действия (StudentView, TutorView, TutorContent…)
    api/auth/                  вход, сессии, приглашения, сброс пароля, первая настройка
    config/                    настройки, отдача сайта, заголовки безопасности
    domain/                    группы, расписание, ДЗ, материалы, абонементы, отчёты, файлы, пользователи
    notify/                    уведомления и задачи по времени (напоминания, сводка, отчёты, уборка)
    notify/push/               web push: шифрование RFC 8291, подпись VAPID, отправка
  src/main/resources/db/migration/   схема базы
web/                           React 18, Vite, TypeScript
  src/student/, tutor/, parent/      экраны по ролям
  src/auth/                    вход, приглашение, новый пароль, настройки
  src/feed.tsx, push.ts        лента и включение уведомлений
  public/sw.js                 service worker: только уведомления, страницы не кэширует
docker-compose.yml             база, сайт, ежедневный бэкап, временный туннель для телефона
```
